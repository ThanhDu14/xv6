\section{Kết luận}

Đã triển khai thành công một web server Apache trên Ubuntu (AWS EC2) đáp ứng
đủ 10 hạng mục kiểm tra: hai virtual host trên cùng một IP, reverse proxy tới
backend Node.js chỉ lắng nghe nội bộ, load balancer ba instance có failover,
HTTPS với redirect 301 và HSTS, tường lửa chỉ mở đúng cổng cần thiết và các
header làm cứng. Bài học lớn nhất là trên môi trường cloud, tường lửa có
nhiều lớp và cần kiểm thử từ bên ngoài chứ không chỉ từ localhost.
